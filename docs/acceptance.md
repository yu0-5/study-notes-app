# 演示与验收清单

本清单用于本地演示和回归检查，不把尚未执行的人工步骤当作已通过结果。

## 准备

1. 按 README 安装依赖，分别启动前端、后端，确认 `/api/health` 返回 `ok`。
2. 用独立浏览器配置或无痕窗口测试，避免修改日常学习资料。始终使用同一个前端地址。
3. 使用仓库内 `examples/http-cache.md` 作为演示资料。默认选择“模拟生成”，无需模型密钥。

## 边界与异常检查

- [ ] 选择 PDF、空文件、超过 1 MiB 的文件时拒绝导入，原资料与笔记仍保留。
- [ ] 长资料整篇超过生成限制时无法确认输入；改选有效片段后可确认。
- [ ] 更改学习偏好后，旧确认快照不会被静默改写，需重新确认。
- [ ] 候选有修改时重新确认或重新生成会询问；取消后保留修改。
- [ ] 切换到另一资料时，不能把旧候选错误追加过去；返回来源后可继续。
- [ ] 对话输入空白或超过 1,000 个 Unicode 码点不能发送；Shift+Enter 换行。中文输入法候选确认用真实输入法单独检查。
- [ ] A 正在回答时切换到 B，A 的片段不显示在 B；返回 A 可继续查看。
- [ ] 停止后保留未完成片段；仅最后一条停止或失败的回答可以重试。
- [ ] 取消删除资料 A：A 的消息、草稿和正在进行的任务均保留。
- [ ] 确认删除正在回答的 A：取消 A 的任务并移除其消息与草稿，剩余资料可以立即提问。
- [ ] A 正在回答时删除 B：A 继续回答，B 的消息、草稿和笔记被清理。
- [ ] 删除最后一份资料：进入空态并禁用提问，不再继续输出旧回答。
- [ ] 删除后不保存就刷新，恢复上次保存的资料；删除后保存再刷新，资料不再恢复。对话始终不参与持久化。
- [ ] 在回答中切换“我的笔记”、回首页再打开，任务和消息不因面板隐藏而丢失。
- [ ] 停止后、生成完成后检查浏览器控制台；桌面与较窄窗口下检查阅读区、输入框和滚动。

真实笔记生成需要另行配置 `.env`，主动选择真实生成才测试，会消耗 API 额度。需人工确认逐段输出、停止保留片段、错误提示、完整结果可编辑追加；它不属于离线自动化检查。

## 会话清理阶段实现说明（2026-11-15）

本轮把 `useStudyChat` 的唯一实例从 `AiAssistantPanel` 提到 `App`，让资料删除与对话清理由同一个事件处理函数协调。消息、草稿和任务细节仍封装在 Hook 中，面板通过 props 获取数据与操作。

删除成功后调用 `clearDocument(id)`：只清除该 ID 的消息和草稿；如果活动回答属于它，先使任务引用失效，再取消任务、释放忙碌状态。取消删除时不调用清理。

仅调用 `abort()` 不足以保护状态：旧任务的回调、`catch` 或 `finally` 可能迟到。因此回调还检查任务身份；更新消息时也拒绝重新创建已删除会话。自动化用例故意模拟取消后仍返回的任务，确认不会恢复旧消息或解除新任务的锁。

本轮实际验证结果：

- 项目本机与不含 `.env`、重新执行 `npm ci` 的独立副本均通过 `npm run check`：24 个 Vitest 用例、两份 SSE 检查、ESLint、TypeScript 和生产构建。
- 独立副本使用 `npm run dev:server` 启动成功；健康检查、生成输入校验与模拟生成接口均返回预期结果。
- 本轮未调用真实模型，也未重新执行真实浏览器视觉或中文输入法验收；上方人工清单保留为待执行项。
- CI 工作流已配置，推送后的远程结果应在 GitHub Actions 中查看。

## Markdown 导出阶段（2026-11-15）

阶段目标：导出当前个人笔记，完整保留 Markdown 原文，并与浏览器内保存状态隔离。

实现分工：

- `src/utils/noteExport.ts`：纯函数处理建议文件名；浏览器下载函数创建 Blob 与临时链接，触发下载后延迟释放 URL，失败路径即时清理。
- `App.handleExportNote`：检查当前资料、空白笔记、读取异常和导入状态；使用当前内存中的 note，并将准备失败转换为界面提示，不更新保存快照。
- `NoteEditor`：展示导出入口与反馈。`exportDisabledReason` 同时用于推导禁用状态和说明原因；反馈仅在资料 ID 与点击时正文都匹配时显示。

完整验收项：

- [x] 未保存内容可以实际下载；中文、emoji、代码块、缩进与首尾空白逐字节匹配 UTF-8 原文，无新增 BOM。
- [x] 文件名替换非法字符，按本地时间命名，长标题截取不拆开普通 emoji。
- [x] 编辑和预览模式导出相同的 Markdown 原文。
- [x] 连续导出生成独立下载；临时链接移除，各次 Object URL 均被释放。
- [x] 导出后仍显示未保存，localStorage 不变；刷新恢复上次保存内容；显式保存后刷新可恢复新内容。
- [x] 切换资料后使用当前标题与笔记，旧反馈不串资料。
- [x] 下载准备失败保留笔记，可以重试；本地保存失败时仍能导出内存内容。
- [x] 空白笔记、无资料、正在导入和读取异常时禁用导出并给出原因。
- [x] 桌面与 1024×768 展开资料栏时，操作按钮可换行，长标题及文件名不撑破面板。
